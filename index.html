IP FIELD NOTES / 001
系統空間方法來源
Taiwan Character IP · Case Study

貓貓蟲咖波
不只可愛。

一個角色如何從表情與動作，長成內容引擎、日常情緒工具、商品生態系，再進入實體空間與跨品牌授權？這份研究拆解的不是外觀，而是讓 IP 長期運作的系統。

角色 DNA內容引擎情緒價值商業轉譯授權系統
Core Thesis

成功的角色，不只是被看見，而是能反覆被使用。

咖波的關鍵在於：角色性格可以持續產生行為；行為產生情緒與內容；內容累積熟悉感；熟悉感再被帶進貼圖、商品、空間與合作。這是一個可持續循環，而非單次爆紅。

01 / SYSTEM

把角色變成一台
內容引擎。

角色不是一張設定圖。當性格能被翻譯成可辨認、可重複、可變化的行為，創作才有機會持續。

THE REPEATABLE ENGINE

角色 → 行為 → 情緒 → 內容 → 社群 → 商品 → 體驗 → 授權

每個環節都能把前一環節累積的認知，轉化為下一個接觸點。商品不是突然插入的廣告，而是角色熟悉感的另一種載體。

角色 Character一眼能辨認的輪廓、表情、性格反差。
行為 Behavior把性格寫成可重複演出的動作。
情緒 Emotion讓觀眾讀懂懶散、貪吃、無辜或荒謬。
內容 Content短篇、四格、動圖、貼圖都能延伸。
社群 Community粉絲用分享、回覆與二創建立習慣。
商品 Product讓喜愛變成可收藏、可使用的物件。
體驗 Experience把角色帶入實體空間與合照情境。
授權 Licensing透過規範維持辨識度與跨品牌一致性。
02 / DNA

反差，讓可愛
不容易被取代。

咖波並非只靠「萌」。外型的可愛、行為的貪吃與荒謬、表情的無辜感形成反差，讓角色更容易被記住。

01 / SILHOUETTE

輪廓先被記住

即使縮小成貼圖，也要保留足夠明確的外型、五官與色塊。

02 / CONTRAST

可愛 × 怪誕

反差帶來辨識度。不是堆砌設定，而是讓不同特質在同一個角色裡相遇。

03 / LOW LANGUAGE

降低語言依賴

清楚的動作與表情讓情緒可以跨語言傳達，也利於貼圖和短影音傳播。

03 / UTILITY

貼圖不是周邊，
而是情緒介面。

貼圖進入聊天的瞬間，角色就從「被觀看的作品」變成「替使用者表達情緒的工具」。

「我不一定要解釋我的心情；我可以直接傳一個角色。」

使用頻率，比一次性曝光更重要

日常情緒、反應、撒嬌、拒絕與耍廢，都是高頻溝通情境。貼圖讓角色在使用者的社交關係中持續出現。

使用者成為分發者

每一次轉傳都是一次自然曝光。角色不只被品牌推送，也被使用者帶進自己的對話與關係裡。

04 / SPACE

當 IP 走進空間，
熟悉感變成體驗。

主題店的價值不只是陳列商品，而是讓粉絲能走進角色世界、停留、拍照並分享。

SPACE AS MEDIA

空間本身就是媒體

第一層建立品牌印象，商品層促成探索與購買，角色場景則提供拍照、記憶與社群分享的理由。

空間設計案例：UNME Design｜Capoo House

UGC LOOP

打卡點不是裝飾，是分享機制

當場景提供清楚的拍攝角度、角色尺度與情緒記憶點，參觀者便能自然產生內容。實體空間因此成為線上傳播的素材來源。

延伸閱讀：UNME Design｜IP 品牌空間策略

05 / SCALE

創作可以自由，
授權不能靠猜。

當角色跨入大型合作，靠創作者個人直覺已經不夠。明確的視覺規範與角色使用原則，有助於不同團隊共同維持一致性。

LICENSING SYSTEM

把角色 DNA 寫成規則

中央社 2026 年報導提到，咖波品牌有超過百頁的授權手冊；大型跨品牌合作也可能需要長時間協調。這說明成熟 IP 的規模化，需要把角色呈現、使用情境與品牌合作要求制度化。

來源：中央社相關報導（2026）

CROSS-MEDIA

不是把圖貼上去就算合作

跨品牌合作要同時考慮角色辨識度、合作品牌規範、商品使用情境與粉絲期待。好的合作讓角色進入新情境，卻不失去原本的性格。

06 / TAKEAWAYS

給 B.Chewy 的
七個可轉用方法。

借鏡系統，不複製表面。不同 IP 的受眾、媒介與商業路徑不同，方法必須依自身創作定位重新設計。

先定義角色 DNA

把外型、性格、慾望、弱點、行為邏輯與不可違反的原則寫清楚。

設計可重複的行為引擎

列出角色在日常情境裡會反覆做的事，讓內容不必每次從零發明。

讓角色提供情緒價值

思考觀眾為什麼需要這個角色：陪伴、宣洩、幽默、療癒或身份表達。

建立角色關係組合

角色與角色之間的慾望、誤解、互補與衝突，能持續產生新的故事。

依媒介重新翻譯

動畫、雕塑、藝術玩具、展覽、教育內容與商品，不應只是同一張圖換尺寸。

先驗證內容，再擴張世界

先建立受眾對角色的情感，再逐步擴張故事、場景與產品線。

提早建立授權規範

整理標準色、比例、表情範圍、禁用方式、商品案例與合作流程。

選擇適合自己的商業路徑

B.Chewy 可更重視藝術創作、動畫、藝術玩具、展覽、教育產品與授權的整合。

Strategic Principle

不要做「另一個咖波」。要建立一個有自己內容引擎的 B.Chewy。

  • 不照抄表面元素：藍色、貓型、粗線條或可愛怪誕只是外觀。
  • 真正值得借鏡的是：角色 DNA、內容引擎、情緒用途、關係引擎、媒介轉譯與授權系統。
  • 用 B.Chewy 自身的藝術、動畫、實體作品與教育方向，設計專屬的成長循環。
