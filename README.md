# 貓貓蟲咖波（Bugcat Capoo）IP 深度研究

這是獨立的編輯式研究網站專案，與 `web-bf` 分開管理。

## 專案目標

- 研究咖波如何把角色性格轉化為可持續的內容、情緒價值、社群習慣、商品與授權系統。
- 以真實圖片搭配來源標註；不以示意圖冒充官方角色照片。
- 兼顧手機與桌面閱讀體驗。
- 部署目標：Cloudflare Pages（先使用 `pages.dev`，確認後再設定自訂網域）。
